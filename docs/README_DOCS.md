## 📞 Getting Help

### Documentation Issues
- Check the **[API Quick Reference Card](./API_QUICK_REFERENCE_CARD.md)** first
- Search the **[API Handover Documentation](./API_HANDOVER_DOCUMENTATION.md)**
- Review **[Payment Quick Reference](./PAYMENT_QUICK_REFERENCE.md)** for payment issues

### Code Issues
- Check browser console (F12) for frontend errors
- Check backend terminal for server errors
- Verify environment variables are set correctly

### API Provider Issues
- Refer to official provider documentation (links above)
- Check provider status pages
- Contact provider support directly
